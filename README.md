# Робочий портал юриста БПД

Єдиний вебпортал інструментів, реєстрів, сервісів документообігу та навчальних ресурсів для юристів системи безоплатної правничої допомоги (БПД), створений на основі інтерфейсу Google Stitch відповідно до Брендбуку БПД 2024.

## Основні можливості

- **16 робочих інструментів і сервісів** у 5 категоріях: *Документообіг*, *Діловодство*, *Оцінювання*, *Сервіси*, *Навчання* (усі зовнішні посилання відкриваються у новій вкладці).
- **Миттєвий пошук та фільтрація** за назвою, ключовими словами й категоріями.
- **Світла та темна тема** зі збереженням вибору у `localStorage`.
- **Екран авторизації (SHA-256)** через вбудований браузерний Web Crypto API (`crypto.subtle.digest`) без зовнішніх бібліотек.
- **Захист від підбору пароля (Brute-force)**: блокування форми на 30 секунд після 5 невдалих спроб зі збереженням стану в `localStorage` та кнопкою «Вийти» у шапці порталу.
- **Заборона індексації пошуковими системами** (`noindex, nofollow`).

## Налаштування пароля доступу

За замовчуванням для тестування встановлено SHA-256 хеш пароля `admin`.  
Щоб встановити постійний робочий пароль:

1. Обчисліть SHA-256 хеш потрібного пароля у форматі hex (нижній регістр).
2. Відкрийте файл [`js/auth.js`](./js/auth.js) та замініть значення константи `EXPECTED_HASH` на новий хеш.
